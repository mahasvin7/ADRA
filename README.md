# ADRA — Pure HTML, CSS & Vanilla JavaScript Edition

This is the **zero-dependency, pure HTML/CSS/JS conversion** of the ADRA Company Ecosystem Website.

No Node.js, no React, no build steps, and no installation required.

Just double-click `index.html` in Windows Explorer, or open this path directly in Chrome, Edge, Safari, or Firefox:

```
file:///C:/Users/mahas/.gemini/antigravity/scratch/adra-vanilla/index.html
```

## File Structure

* `index.html` — Complete semantic single-page architecture containing all sections, overlays, and modals.
* `css/tokens.css` — Centralized color tokens (`#111411`, `#EDEBE3`, `#B9C9B5`, `#C7B58A`, `#9B9E96`) and Google Fonts.
* `css/styles.css` — Complete layout styles, hairlines, grain texture, orbital physics, and alternating grids.
* `js/data.js` — **Editable single source of truth**: all 4 divisions, 20 startups, copy, and links.
* `js/emblems.js` — Procedural architectural monograph generator (supports custom logos too).
* `js/app.js` — Complete application logic (orbit physics with upright cards, 4s showcase rotation, alternating details, modal focus trap/ESC, contact validation, and local registry storage).
* `logos/` — Drop custom `.svg` or `.png` logos here and reference them in `js/data.js`.
